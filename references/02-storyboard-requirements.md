# 生成分镜要求

请根据用户提供的剧本、故事梗概和场景图，生成符合场景空间关系与视觉逻辑的竖屏短剧分镜。

## 一、场景图分析要求

1. 仔细识别场景图中的空间布局、人物位置、道具位置、运动方向、人物与道具之间的相对关系、前后景层次以及可见环境元素。
2. 场景图中使用不同颜色的框标注人物或道具，必须按照标注说明，准确理解每个框对应的人物或道具。
3. 场景图是分镜中「画面内容」「光影氛围」「背景结构」的重要依据，生成时保证镜头画面与场景图空间关系一致。
4. 以故事发生时间作为整体光色基准，以场景图中可见的光源方向、明暗关系和空间遮挡关系作为光影与空间依据。
5. 场景图中某些位置、光源或空间结构不清晰时，采用保守、真实、合理的描述，不得编造不存在的环境、门窗、家具或道具。
6. 镜头视角变化时，也必须保持人物、道具、前后景和空间方向连续一致。

## 二、分镜场景光影要求

1. 每个不同场景对应的分镜最上方，必须先写：

```
镜号X-Y场景：XXX
主光影氛围：XXX
现实质感，真实画面风格、物理真实材质，不加字幕，不加背景音乐。
```

2. 「主光影氛围」需较详细描述，符合故事发生时段和场景图光源方向与明暗关系，并写明整体明暗反差。可参考：低角度暖黄侧逆光，浓郁金橙硬质日光，高对比度明暗分割，暖黄夕阳勾勒人物轮廓，清晰硬朗的明暗交界线，大面积亮部覆盖场景，阴影区域深邃沉暗。
3. 每镜「光影氛围」简洁准确，写清光线从画面哪个位置投入＋整体氛围，纯描述、不套「明暗反差X，氛围XX」固定结尾。

## 三、分镜格式要求

1. 严格按《竖屏短剧分镜格式模版》的完整字段、字段名称、字段顺序和整体结构输出。
2. 不得擅自增加无关字段。
3. 不得擅自修改字段名称。
4. 每个镜头都完整填写模板要求的内容。

## 四、人物与镜头要求

1. 尽量用单人镜头，少用多人镜头和全景，除非表现亲密/冲突关系或必须交代整体空间。

2. 单人镜「画面内容」不设栏名，但**聚焦独立成行**——镜头语法行之后先单独一行写「此时画面仅需聚焦XX」（聚焦面部/整体写角色名，聚焦手部等局部写「XX的手部」），随后画面内容直接描述人物动作、走位、调度。不写「位于画X、处于XX状态、面向画X」三件套，位置与朝向融入动作描述。

3. 单人镜必须明确人物在画面中的位置：画面中央、画面左侧、画面右侧、画面前景、画面后景（可简写画左／画右）。位置可融入动作自然表述，但方位词必须出现，不得省略。

4. 单人镜必须明确人物朝向和视线：面向镜头、面向画左、面向画右、看向画外的XX。朝向可融入动作自然表述，但朝向词（面向画左／面向画右等）必须出现，不得省略。

5. 多人镜明确每人位置、状态和朝向，最后明确视线关系：互相对视、XX看向XX、共同看向画外的XX。

6. 避免大量平视，多用轻微仰视、轻微俯视、低机位、手持镜头及场景化视角（镜面观察视角、镜中视角、针板高度的侧视等）。

7. 位置表述只用画左、画右、画面前景、画面后景、画面中央；不用「左边/右边」。

8. 运镜按剧情节奏大胆设计，可多使用：固定机位、缓慢推近、快速推近、缓慢后拉、缓慢后撤、平稳跟拍、缓慢横移、缓慢环绕、缓慢上摇、缓慢下摇、手持微晃、运动急停等。**以上为参考，可自由使用更多种类。**

9. 镜头语言：基础通识性内容直接写——景别（大全景／全景／中景／近景／特写）、运镜（推／拉／摇／移／跟／环绕／俯冲／后拉／上摇／手持晃动）、机位（低角度／俯视／第一人称）；热门运镜方式直接写——一镜到底、希区柯克变焦、航拍视角、FPV、子弹时间、手持镜头、回弹变速等。

10. 过于小众、专业的名词须转换为「名词 + 描述性解释」，如「移焦，画面焦点发生平滑转变，原本在前景清晰的树木变模糊，背景中的人物由模糊逐渐变得清晰」。

11. 转场镜头写清触发点与方式，尽可能把转场时间、方式都写明，如「第 5s 快速向左横移转场（向左擦除+自然叠化）」。

## 五、人物状态与动作要求

1. 每个镜头明确人物状态：站立、坐在椅子上、倚靠墙边、蹲在地上、躺在床上、正向画右走动、停在门边等。**画面内出镜的所有人物（含仅轮廓/局部出镜的次要人物）都须交代状态，不得只写朝向不写坐/站/蹲。**
2. 镜头之间人物状态连续统一；除非镜内明确表现起身、坐下、转身、倒下、移动，否则沿用上一镜状态。
3. 台词可配自然小动作，动作须服务情绪和台词，不添加无关大幅动作。
4. 凡手持/拎/拿/端/掏/抓/甩/牵等持物动作，必须写明具体左右手（如「左手拎着包」「右手拿着手机」），不得写「手里/一只手/另一只手」。

5. 动作优先用概括性描述（如「连续做了几组高抬腿和空翻」「双方展开近身搏斗」），只在少数有记忆点的动作上写出具体细节，不建议重复写相同的动作。

6. 表情用描述性语句、减少成语使用（如「津津有味地吃饭」写为「脸上带着满足的笑容，大口地吃饭」）；画面内容可写可见的神态/表情动作，情绪形容词仍归「人物情绪」栏。

## 六、台词处理要求

1. 台词可在不改变原意下润色，更符合口语和短剧节奏。
2. 同一人物台词分散在多镜时，先合并再按长度和内容分配镜头。
3. 台词过长按意义拆分到其他人物的反应镜头；每镜台词字数按 3–4 字/秒折算、不超过标注时长。
4. 拆分到反应镜头的台词须标「画外音」；前半句留本镜、后半句压到反应镜。
5. 台词栏格式：内心声 `人物 内心声OS：台词`；画外音 `人物（画外音，语气）：台词`；不写面向画左/画右的朝向。

6. 避免在台词后复述词语并追加语气、表情、动作等描述，此类描述容易诱发字幕生成。需要对台词做差异化要求（投喂 AI 视频工具）时，按「角色台词（情绪）：内容」格式拆分描述（如「周女士台词（难以置信）：像……」「周女士台词（声音发颤）：太像了。」）；分镜 Markdown 内的台词栏仍用第 5 条的内心声OS／画外音格式。

## 七、情绪转折处理要求

1. 情绪转折前适当拉长镜头时长，让人物完成动作、停顿或面部变化，再写「然后开始台词」。
2. 强烈情绪用「略微」修饰：眉眼略微、面色略微、神色略微，避免夸张失真。

3. 眼睛发光规避（最高优先级）：模型对人物情绪过度响应时瞳孔会出现蓝光/红光等非自然发光。① 提示词以最高优先级明确约束「人物为正常人眼、不发光」，并限制环境光仅作用于面部轮廓——此约束写进**场景头主光影氛围末尾**；② 避免将情绪直接描述为眼睛的特效化表现，将「狂热」「极度震惊」等极端情绪词**先降级为常规词**（如「惊叹」「震惊」）再写，降级后仍加「略微」修饰。

## 八、输出前自检要求

1. **单人镜出镜检查**：出现其他人物写 `仅XX的轮廓/某些身体部位出镜` 并交代其坐/站/蹲状态；只拍局部不露脸写「人物面部不出镜」。
2. **空镜检查**：纯空镜以 `纯空镜。` 起头，含「构图避开人物及人物倒影」。
3. **情绪转折检查**：转折前预留停顿/动作/面部变化；强情绪用「略微」。
4. **人物情绪格式检查**：`人物情绪：人物：眉眼XX、面色XX、神色XX。`（句末句号）；保留眉眼/面色/神色顺序；无面部出镜去掉该项；不写红眼框等夸张形容词。
5. **台词格式检查**：写清语气，内心声标「内心声OS」、拆出部分标「画外音」，台词句末句号，不写朝向；无台词去掉该项。
6. **光影氛围检查**：每镜写光从画面哪个位置投入＋整体氛围，不套固定结尾。
7. **气氛粒子检查**：每镜有「气氛粒子」栏。
8. **连续性检查**：镜号连续无重号；状态/站位/朝向/持物衔接；跨镜转场在画面/声音/背景三处写清；总时长与文件头一致。
9. **人物指代检查**：独立栏目（主光影氛围／同期声音效／光影氛围／背景结构／气氛粒子）无「他/她/它」代词、均写具体角色名；画面内容栏与台词栏可用代词。
10. **持物左右手检查**：持物/拎/拿/端/掏/抓/甩/牵等动作均写明左右手，无「手里/一只手/另一只手」。
11. **台词长度检查**：每镜台词字数按 3–4 字/秒折算、不超过标注时长；超长已拆分到反应镜。
12. **镜头语言检查**：通识词/热门运镜直接写；小众专业名词已转「名词+描述性解释」；转场写明触发点+时间+方式。
13. **动作/表情检查**：动作用概括性描述、不重复；表情用描述性语句、减成语。
14. **眼睛发光规避检查**：无「狂热/极度震惊」等强烈情绪特效词；已约束「人物为正常人眼、不发光」；台词栏未复述词语追加语气/表情/动作。
