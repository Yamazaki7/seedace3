# 提示词汇总（镜头 & 构图）

> 竖屏短剧（9:16）常用**镜头运动**与**画面构图**的纯文字提示词库，可直接复制进分镜「镜头」栏与「画面内容／背景结构」栏。**本词库为参考，可自由使用更多其他种类。**

## 使用说明

1. **写入位置**
   - 镜头运动词条 → 分镜「镜头」栏末项（面部角度＋焦段＋景深＋拍摄视角＋**镜头[景别][运镜]**，景别与运镜合并写自然语言）。
   - 画面技法／前景词条 → 分镜「镜头」栏末项之后的第 7 项（如 `水滴前景/湿玻璃折射`、`拉焦/焦点转移`、`镜面反射/倒影构图`）。
   - 构图词条 → 分镜「画面内容」栏与「背景结构」栏。
   - 空镜两分：完全无人（也无倒影）写「纯空镜」、构图避开人物及人物倒影；只拍局部不露脸归单人镜、写「人物面部不出镜」。
2. **组合原则**：一个镜头 = 1 个主运镜 +（可选）1 个修饰；构图 = 1 个主构图 +（可选）1 个辅助；最多 2 个。
3. **焦段硬匹配**：全景 35mm／中景·中近景 50mm／近景 85mm／特写 100mm；竖屏 9:16。
4. **站位与朝向**：凡有人物的镜头写明「位于画面哪里（画左／画右／画面中／前景／后景）＋面朝哪里」；正反打互指、全场不越轴。
5. **多段式转接**：一镜内可写转接——「全景转环绕中景／35mm转50mm／深景深转浅景深」。
6. **转场写明触发点与方式**：转场镜头写清触发点、时间、方式（如「第 5s 快速向左横移转场（向左擦除+自然叠化）」）。
7. **禁忌**：不写「眼里有光／眼底的光」；抽象情绪不写进「画面内容」。

## 一、景别与焦段基线（竖屏）

| 景别 | 焦段 | 画面占比 | 常用场景 |
|:--|:--:|:--|:--|
| 大全景 | 35mm | 人物极小 | 转场、天色、战场／城池（少用） |
| 全景 | 35mm | 人物约半身到全身 | 空间交代、动作与站位关系 |
| 中景 | 50mm | 人物膝盖以上 | 关系戏、行进、动作衔接 |
| 中近景 | 50mm | 人物腰部以上 | 对话主力景别 |
| 近景 | 85mm | 肩部以上 | 情绪反应、台词镜 |
| 特写 | 100mm | 面部／局部 | 强情绪、关键道具（极浅景深） |
| 大特写／空镜特写 | 100mm | 眼睛、手、物件 | 情绪顶点、伏笔、转场 |

## 二、常用镜头运动词库（30 条）

| 序号 | 类型 | 适用情节 | 提示词 |
|:--:|:--|:--|:--|
| 1 | 手持微晃 | 不安、真实、跟人 | 手持摄影，轻微自然抖动，画面有呼吸感，运镜跟住人物，轻微镜头漂移 |
| 2 | 缓慢推近 | 情绪铺垫、压迫渐起 | 镜头匀速缓慢向前推近，柔和平缓，情绪层层递进 |
| 3 | 快速推近 | 震惊、爆发、锁定 | 镜头快速向前急推，瞬间逼近主体，带动态冲击感 |
| 4 | 缓慢后拉 | 揭示环境、抽离、收束 | 镜头匀速向后拉远，取景范围逐步扩大，人物渐小、环境逐步露出 |
| 5 | 快速后拉 | 惊变、甩开、抽离 | 镜头快速向后拉开，人物迅速缩小，环境扑面展开 |
| 6 | 正面跟拍 | 行走／移动中的对话 | 镜头正对人物面部，与人物同步向前移动，跟随行进 |
| 7 | 侧面跟拍 | 并行、骑马、奔跑 | 镜头与人物平行横移跟拍，人物在画面中保持同一位次 |
| 8 | 背后跟拍 | 进入空间、悬念 | 镜头在人物身后同向跟随，只见背影与前方环境 |
| 9 | 缓慢横移 | 扫视、关系交代 | 镜头水平匀速横移，依次带过画面中的主体与环境 |
| 10 | 缓慢环绕 | 关系、仪式感、压迫 | 摄影机以人物为圆心缓慢弧形环绕，人物居中、背景缓缓流转 |
| 11 | 快速环绕 | 眩晕、冲突、失控 | 快速环绕甩镜，背景拉成流动虚影，人物锁在画面中心 |
| 12 | 缓慢上摇（升摇） | 人物出场、气场 | 机位固定，镜头垂直向上缓慢摇动，自人物脚部升到面部并锁定 |
| 13 | 缓慢下摇 | 自上而下带入角色 | 镜头自上方缓慢下摇、随之下移，自上而下依次揭出环境与人物 |
| 14 | 俯冲推进 | 大场面切入、聚焦 | 高空俯冲推进，视角由大全景快速压向地面主体，运动模糊 |
| 15 | 希区柯克变焦 | 眩晕、恐惧、顿悟 | 机位后退同时镜头反向变焦，人物尺寸不变、背景空间拉伸扭曲 |
| 16 | 焦点转移 | 两层信息、悬念 | 镜头不动，焦点自前景物体切到后景（或反向），景深调度引导视线 |
| 17 | 主观视角 POV | 代入、恍惚、晕眩 | 第一人称主观视角，镜头随人物视线移动，轻微晃动与呼吸感 |
| 18 | 过肩 | 对峙式对话 | 过肩镜头，前景肩部与后脑勺虚化，焦点落在对面人物面部 |
| 19 | 遮挡起幅带入 | 开场、转场、换场 | 起幅被前景物体（旗面／枝叶／门框／檐口／帷幔）虚化遮满，镜头后拉或下拉退出遮挡，带入人物与环境 |
| 20 | 甩镜 | 突发、强转场 | 镜头快速横向甩动，画面拉出动态模糊后急停定住 |
| 21 | 运动急停 | 定格、强调、收束 | 镜头运动中突然急停锁定，画面瞬间定格，制造停顿与强调感 |
| 22 | 缓慢后撤 | 抽离、退让、揭示 | 镜头匀速缓慢向后撤退，取景渐广，人物与环境的距离感逐步拉开 |
| 23 | 缓慢上摇 | 自下而上揭示 | 镜头自下而上缓慢摇动，从低处景别升到人物面部并锁定 |
| 24 | 固定机位 | 静观、对峙、稳定 | 机位固定不动，画面静止，主体在固定景别中表演 |
| 25 | 一镜到底 | 沉浸、连贯、长镜头叙事 | 单个镜头连续拍摄、不剪辑，镜头随人物走位连贯移动、场面调度一气呵成 |
| 26 | 航拍视角 | 大场面、俯瞰、开场 | 无人机高空俯瞰拍摄，鸟瞰全景，人物与地貌尽收眼底 |
| 27 | FPV 第一视角 | 极速、代入、穿梭 | 第一人称穿越视角，镜头高速穿梭飞行，强烈速度感与沉浸感 |
| 28 | 子弹时间 | 动作定格、慢镜环绕 | 时间近乎凝固，镜头绕主体缓慢环绕、主体动作以慢动作展开 |
| 29 | 手持镜头 | 纪实、真实、临场 | 手持摄影、自然晃动，画面带呼吸感与现场感 |
| 30 | 回弹变速 | 节奏顿挫、张力 | 动作快慢交替、速度忽快忽慢地回弹变化，制造节奏顿挫 |

> 用法：连续镜头里主运镜不要重复堆叠——推、拉、移、摇、环绕交替；动作戏可用多段式转接。
>
> **小众专业名词**：过于小众、专业的名词（如「移焦」）须转换为「名词 + 描述性解释」——「移焦，画面焦点发生平滑转变，原本在前景清晰的树木变模糊，背景中的人物由模糊逐渐变得清晰」。基础通识词（推/拉/摇/移/跟/环绕/俯冲/后拉/上摇/手持晃动）与热门运镜（一镜到底/希区柯克变焦/航拍/FPV/子弹时间/手持镜头/回弹变速）可直接写、无需解释。

## 三、常用构图词库（21 条）

| 序号 | 构图 | 适用情节 | 提示词 |
|:--:|:--|:--|:--|
| 1 | 单人镜 | 情绪主力、台词镜 | 单人镜头，画面聚焦人物面部，背景虚化，人物位于画面中央（偏左／偏右） |
| 2 | 中心构图 | 稳定、仪式感、权力 | 人物居中，画面左右均衡，构图端正对称 |
| 3 | 三分法／九宫格 | 常规叙事 | 人物置于画面三分线交点，头顶留少量空间，视线方向留出余白 |
| 4 | 视线留白 | 凝望、对话 | 人物靠画面一侧，面朝方向留出更大空间，画面有呼吸感 |
| 5 | 过肩构图 | 对话、正反打 | 前景肩部与后脑勺虚化框住画面边缘，焦点落在对面人物面部 |
| 6 | 框架构图 | 门洞、窗棂、廊柱 | 以门框／窗棂／廊柱作前景框架，人物位于框内，框外压暗 |
| 7 | 前景遮挡（窥视） | 悬疑、偷看、铺垫 | 虚化前景障碍物遮挡局部画面，人物只露部分，信息不完整 |
| 8 | 大小对比／压迫 | 权力差、威胁 | 弱势人物占画面小，强势对象占大面积，形成压制感 |
| 9 | 低角度仰拍 | 强势、威慑 | 贴地低机位向上仰拍，人物高耸占据画面，顶棚或天空占上方 |
| 10 | 轻微俯拍 | 弱势、审视、被看 | 机位略高于人物向下拍，人物显得被动、被俯视 |
| 11 | 荷兰角（倾斜） | 不安、失衡 | 画面轻微倾斜，水平线歪斜，角度很小不夸张 |
| 12 | 纵深引导线 | 空间纵深、去向 | 利用街道／走廊／殿柱／栅栏作引导线，向画面深处汇聚 |
| 13 | 背影构图 | 离别、抉择、未知 | 人物背影朝画面深处，看不到面部，情绪留给姿态与环境 |
| 14 | 双人并排（齐头） | 同行、亲密、骑行 | 两人并排同向、齐头，间距均匀，同朝画面一侧缓行 |
| 15 | 双人对立 | 对峙、谈判 | 两人分居画左画右、相对而立，中间留出一段空地 |
| 16 | 正反打互指 | 对话主力 | A 占画左、面朝画右；B 占画右、面朝画左；机位互换时左右同步镜像 |
| 17 | 镜像／倒影 | 唯美、暗示、心理 | 利用水面／铜镜／玻璃倒影，实像与虚像同框，倒影半朦胧 |
| 18 | 负空间／留白 | 孤独、渺小 | 人物偏居画面一角，大面积空景（天空／墙面／旷野）形成留白 |
| 19 | 镜面反射／倒影构图 | 唯美、暗示、心理 | 利用镜面／玻璃／水面反射，实像与虚像同框，倒影半朦胧虚化 |
| 20 | 水滴前景／湿玻璃折射 | 唯美、迷离、遮挡 | 前景玻璃水滴／水痕，光线经水滴折射，画面蒙一层滤光质感 |
| 21 | 拉焦／焦点转移 | 两层信息、悬念 | 焦点自前景物体切到后景（或反向），景深调度引导视线 |

## 四、短剧常用镜头组合套路

| 叙事目的 | 镜头序列 |
|:--|:--|
| 开场带入 | 遮挡起幅 → 下拉或后拉退出遮挡 → 带入人物与环境 |
| 空间交代 | 空镜后拉 → 全景建立 → 主体单人镜 |
| 骑行／赶路 | 并排齐头同向 → 侧面跟拍横移 → 前景遮挡起幅带入 |
| 对话正反打 | A 单人近景 ↔ B 单人近景（互指）→ 插入反应镜 |
| 情绪爆发 | 缓慢推近 → 快速急推特写 → 手持微晃 |
| 震惊／真相 | 快速急推特写 → 希区柯克变焦 → 反应近景 |
| 关系变化 | 双人并排 → 双人对立 → 单人中景（拉开距离） |
| 权力压迫 | 低角度仰拍 → 大小对比构图 → 缓慢环绕 |
| 悬念／窥视 | 前景遮挡 → 前景遮挡横移 → 焦点变换 |
| 主观代入 | POV → 手持微晃 → 主观式变焦／焦点变换 |
| 结尾收束 | 缓慢推近特写 → 缓慢后拉全景 → 高空拉远（留白） |

## 五、竖屏构图纪律（硬性）

- **9:16 竖屏**：人物竖向占据画面，横向信息压缩进竖幅，宁可上下叠层次，不要左右铺太开。
- **多用单人镜与近景**，少用多人镜与大全景；大全景只用于转场、天色、大场面。
- **位置表述统一**：画左、画右、画面中、前景、后景；禁止「左边／右边」。
- **视线方向留白**：人物面朝哪边，哪边留出空间；对切时两侧留白方向互指。
- **不越轴**：同一场戏机位在轴线一侧；正反打左右镜像换算，并重新换算入光方向。
- **景深匹配情绪**：情绪特写＝极浅／浅景深；叙事动作与全景＝深景深。
- **前景遮挡起幅**：换场、开场优先用实体遮挡物起幅，再后拉／下拉揭出人与环境。
- **状态延续**：站／坐／跪／骑、持物状态与上一镜衔接；镜内起坐、转身、移动要写明。
- **一镜一主运镜**；动作戏可用多段式转接，并在「镜头」栏写清「A 转 B／焦段转／景深转」。
- **空镜两分**：完全无人（也无倒影）写「纯空镜」、构图避开人物及人物倒影；只拍身体局部不露脸归单人镜、写「人物面部不出镜」。
- **跨镜衔接**：相邻镜的转场/匹配剪辑，在画面内容、同期声音效、背景结构三处写清（如「沿同一画面纵轴下落」「提前0.3秒引入」「切点对齐」）。
