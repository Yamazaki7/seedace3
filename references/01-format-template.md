# 竖屏短剧分镜格式模版（新格式九栏）

## 使用说明

1. 分镜必须**严格按下文栏目顺序、字段名称输出**，不得擅自增加无关字段，不得修改字段名称。
2. `人物情绪` 与 `台词` 是**条件字段**：无人物面部出镜时去掉 `人物情绪`，无台词时去掉 `台词`。
3. 每条镜头都必须完整填写必填内容，字段名已含说明的按字段名口径写。

## 一、核心参数硬性统一规则

### 1.1 面部角度优先级（仅三种表述）

| 表述         | 适用场景            |
|:------------ |:------------------- |
| **正面**     | 强情绪 / 特写神态   |
| **正面微侧** | 常规对话交流        |
| **侧面**     | 人物动作 / 行进调度 |

### 1.2 焦段硬性匹配

| 景别          | 固定焦段 |
|:------------- |:-------- |
| 全景          | 35mm     |
| 中景 / 中近景 | 50mm     |
| 近景          | 85mm     |
| 特写          | 100mm    |

### 1.3 景深规则

| 镜头类型            | 景深          |
|:------------------- |:------------- |
| 情绪特写            | 极浅 / 浅景深 |
| 叙事动作 / 全景环境 | 深景深        |

### 1.4 拍摄视角（可场景化）

| 类型       | 适用场景                                                     |
|:---------- |:------------------------------------------------------------ |
| 轻微仰视   | 强势、气势、压迫                                             |
| 轻微俯视   | 审视、俯看、交代空间                                         |
| 平视       | 常规对白、稳定                                               |
| 超低机位   | 戏剧性、威慑                                                 |
| 场景化视角 | 按镜头实际取景自创，如 `镜面观察视角`、`镜中视角`、`针板高度的侧视` |

### 1.5 镜头运动（运镜词库，参考、可扩展）

固定镜头不过多；运镜按剧情自由设计。常用：缓推、急推、缓慢推近、快速急推、缓慢后拉、缓慢后撤、缓慢上摇、向下摇镜、运动急停、手持微晃、正面跟拍、侧面跟拍、背后跟拍、横移、缓慢横移、缓慢环绕、焦点变换、升摇、下摇、甩镜等。**以上为参考，可自由使用更多种类。**

### 1.6 时长计算规则

| 情况                                 | 语速 / 时长                            |
|:------------------------------------ |:-------------------------------------- |
| 普通对白                             | 每秒约 3–4 个汉字                      |
| 强调、哽咽、停顿、迟疑、边做动作边说 | 每秒约 2–3 个汉字                      |
| 动作前摇、反应、镜头切换             | 必须另外计时，不得只按台词字数估算     |
| 人物无台词的反应镜头                 | 固定 1–2 秒                            |

## 二、固定分镜栏目顺序（九栏）

| 顺序 | 栏目 | 必填 | 格式 / 要求摘要 |
|:----:|:---- |:----:|:-------------- |
| 1 | 镜号 \| 时长 | 必填 | `镜号X \| X秒` |
| 2 | 面部角度＋焦段＋景深＋拍摄视角＋镜头[景别][运镜]（＋画面技法/前景） | 必填 | 景别与运镜合并写自然语言「镜头[景别][运镜]」，需要时追加画面技法/前景 |
| 3 | 画面内容 | 必填 | 不设栏名；单人镜先写「此时画面仅需聚焦XX」独立行、再写动作；纯空镜以 `纯空镜。` 起头 |
| 4 | 人物情绪 | 有面部出镜时必填 | 短句形容词，聚焦眉眼、面色、神色，句末加句号 |
| 5 | 台词 | 有台词时必填 | `人物 内心声OS／人物（画外音，语气）：台词内容。`（句末句号） |
| 6 | 同期声音效 | 必填 | 环境音、动作音、氛围音、跨镜声音衔接 |
| 7 | 光影氛围 | 必填 | 写光源方向与整体氛围，纯描述 |
| 8 | 背景结构 | 必填 | 空间关系、环境布局、纵深层次、构图基调、跨镜接续 |
| 9 | 气氛粒子 | 必填 | 画面内飘浮粒子（水滴/水痕/水汽/浮尘/纤维）的运动 |

## 三、逐项填写要求

**① 镜号｜时长**：`镜号X | X秒`，时长按 §1.6 计算。

**② 镜头语法行**：顺序固定「面部角度 + 焦段 + 景深 + 拍摄视角 + 镜头[景别][运镜]」——景别与运镜合并写成自然语言（如「镜头中景平稳跟拍」「镜头近景缓慢推近」），焦段/景深/视角保留符号；需要时追加「画面技法／前景」（如 `水滴前景/湿玻璃折射`、`拉焦/焦点转移`、`镜面反射/倒影构图`）。焦段符合 §1.2，景深符合 §1.3。

**③ 画面内容（不设栏名）**：单人镜先独立一行写「此时画面仅需聚焦XX」（聚焦面部/整体写角色名，聚焦手部等局部写「XX的手部」），随后画面内容客观描述画面、动作、走位、互动细节；纯空镜以 `纯空镜。` 起首；用了「拉焦/焦点转移」等画面技法的镜头，可直接写焦点转移动作、省略聚焦行。站位与朝向必须出现：位置写「画面中央／画面左侧／画面右侧／画面前景／画面后景」，朝向写「面向画左／面向画右／面向镜头／看向画外」。不写内心情绪状态与说话语气，但可写可见的神态/表情动作（扯嘴角、皱眉、垂眼等）；严禁写「人物眼中有光」。纯空镜须写「构图避开人物及人物倒影」；只拍局部不露脸写「人物面部不出镜」。

**④ 人物情绪**：仅短句形容词，聚焦眉眼/面色/神色，句末加句号，不写长句、不写心理活动。无人物面部出镜时去掉该项。

**⑤ 台词**：内心声 `人物 内心声OS：台词。`、画外音 `人物（画外音，语气）：台词。`，台词句末加句号，不写朝向。每镜台词不超过 5 秒、字数按 3–4 字/秒折算不超过标注时长，超长拆分到对方反应镜、拆出部分标「画外音」。无台词时去掉该项。

**⑥ 同期声音效**：环境音、动作音、氛围音；跨镜转场时可写声音衔接（如「提前0.3秒引入」「切点接住节拍」）。

**⑦ 光影氛围**：写清光源方向、明暗反差、光影层次、氛围基调，纯描述、不套「明暗反差X，氛围XX」固定结尾。

**⑧ 背景结构**：空间关系、环境布局、纵深层次、构图基调，可写跨镜接续（如「与上一镜水滴占据同一画面纵轴」）。

**⑨ 气氛粒子**：漂浮粒子的种类、分布与运动状态。

**⑩ 人物指代**：独立栏目（主光影氛围／同期声音效／光影氛围／背景结构／气氛粒子）里指代人物写具体角色名，不用「他/她/它」代词；画面内容栏与台词栏可用代词。

**⑪ 持物左右手**：凡手持/拎/拿/端/掏/抓/甩/牵等持物动作，画面内容必须写明具体左右手（如「左手拎着包」「右手拿着手机」），不得写「手里/一只手/另一只手」。

**⑫ 视线落点**：看向画外角色时，可写「画外的角色名」点明视线对象（如「看向画右下方画外的对方」），让视线关系清晰。

**⑬ 反应特写呼应**：内心声OS/台词提到某人时，可切该人的反应/状态特写，形成「说到谁、镜头给谁」的呼应，让画面连贯。

## 四、场景头

```
镜号X-Y场景：XXX
主光影氛围：XXX（详细段落，含光源类型与方向、明暗反差、色温、光质、质感）
现实质感，真实画面风格、物理真实材质，不加字幕，不加背景音乐。
```

## 五、标准化成品示例

### 5.1 单镜格式骨架

```
镜号X | X秒
面部角度+焦段+景深+拍摄视角+镜头[景别][运镜][+画面技法/前景]
此时画面仅需聚焦XX（纯空镜省略此行）
纯空镜。取某处景物，构图避开人物及人物倒影；具体景物细节描述。（或）XX 位于画面XX、面向画X，人物动作、走位、调度、互动细节，贴合镜头运动节奏。此处不要写人物情绪和说话语气。
人物情绪：人物：眉眼XX、面色XX、神色XX。
台词：人物 内心声OS／人物（画外音，语气）：台词内容。
同期声音效：场景环境音、人物动作音、环境底噪、氛围音效
光影氛围：光从画面哪个位置柔和投入，高对比冷暖光影，整体氛围。
背景结构：环境陈设、纵深层次，构图特点，烘托整体剧情氛围。
气氛粒子：漂浮粒子的种类、分布与运动状态。
```
