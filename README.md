竖屏短剧分镜工业化拆分 skill（新格式 v3）。依据剧本、当集梗概与场景图，按三阶段门控流程产出竖屏短剧分镜 Markdown。

**关键字：seedace3**

## v3 相对 v2 的升级（实际拆分踩坑沉淀）

在 v2（新格式九栏）基础上，新增/强化 5 条硬规则：

1. **台词长度**：每镜台词字数按「普通对白 3–4 字/秒、强调 2–3 字/秒」折算、不超过标注时长；超长一律拆分到对方反应镜、拆出部分标「画外音」。
2. **持物左右手**：手持/拎/拿/端/掏/抓/甩/牵等动作必须写明具体左右手，不用「手里/一只手/另一只手」。
3. **视线落点**：看向画外角色时写「画外的角色名」（如「看向画右下方画外的对方」），点明视线对象。
4. **反应特写呼应**：内心声OS/台词提到某人时切该人反应/状态特写，形成「说到谁、镜头给谁」的呼应，让画面连贯。
5. **聚焦独立成行**：单人镜在镜头语法行之后单独一行写「此时画面仅需聚焦XX」（聚焦面部/整体写角色名、聚焦手部写「XX的手部」），画面内容直接描述动作调度、不再写「画面聚焦」；纯空镜省略聚焦行。

v3 同时完整保留 v2 全部规则：句末句号、方位词完整形式（画面中央/画面左侧/画面右侧）、独立栏目写具体角色名不用「他/她」简写、焦段硬匹配、空镜两分、跨镜衔接、气氛粒子等，输出前自检清单扩至 **12 项**。

## 新格式九栏

`镜号|时长` → `镜头语法行（景别+运镜自然语言＋可选画面技法/前景）` → `画面内容（无栏名，聚焦独立成行）` → `人物情绪` → `台词` → `同期声音效` → `光影氛围` → `背景结构` → `气氛粒子`

词库（运镜/机位/光影/构图/微表情）均为参考、可自由扩展。
